# Research directory

This directory contains only sanitized, independently useful evidence summaries.

Allowed:

- aggregate counts;
- package/version/hash/certificate metadata;
- high-level behavior descriptions;
- public source references;
- test plans and evidence templates.

Forbidden:

- APK files;
- decrypted/raw competitor datasets;
- embedded encryption/signing secrets;
- decompiled source/disassembly dumps;
- proprietary backgrounds/icons/resources;
- traffic payloads obtained by bypassing protection;
- personal data or credentials.

Static evidence is labeled `CONFIRMED_STATIC`, not runtime fact. Runtime evidence must be reproducible and recorded under [BLACK_BOX_VALIDATION_PLAN.md](../BLACK_BOX_VALIDATION_PLAN.md).
