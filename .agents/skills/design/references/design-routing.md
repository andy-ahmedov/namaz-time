# Design routing

Choose the requested deliverable, not every skill with overlapping keywords.

| Concern | Available route |
|---|---|
| NamazTime TV display/settings | android-tv-screen |
| Compose implementation correctness | compose-agent |
| Brand identity/voice | brand |
| Shared tokens/components | design-system |
| React/shadcn/Tailwind | ui-styling |
| Local style/UX catalog research | ui-ux-pro-max |
| HTML presentation | slides |
| Banner/cover asset | banner-design |
| Logo, CIP, icon or social image | Corresponding reference in design/SKILL.md |

Use multiple routes only for distinct concerns present in the request. Do not
create a full brand package for a component fix, invoke absent skills, or choose
a skill at random. Run documented .agents/skills commands from repository root.
